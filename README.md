# 東浪工作室網站

靜態網站（GitHub Pages）＋ Google Apps Script 預約後端。

- `index.html`：網站本體（首頁、台東浪子、服務價目、地點、線上預約）
- `img/`：圖片
- `apps-script/Code.gs`：預約後端，負責讀取日曆「4 工作/家教」的忙碌時段、建立【待確認】活動，並寄信通知

## 預約流程

1. 客人選擇地點、時長和日期，網站只會顯示還能約的時段。日曆裡已經有活動的時段，前後各多留 30 分鐘，都會顯示為已約。
2. 客人填好貴姓和手機後送出，日曆裡就會多一筆灰色活動，標題像「【待確認】#N MK巨蛋-2300」，同時會寄信到你的 Gmail。
   - 如果這支手機過去兩年曾出現在日曆裡，就標 #O，否則標 #N。
3. 你在 LINE 跟客人確認後，把標題的「【待確認】」刪掉。預約不成立的話，直接刪除這筆活動，時段就會重新開放。

客人只看得到哪些時段忙碌，看不到活動的標題和內容。

## 部署預約後端（只要做一次，大約 5 分鐘）

1. 開啟 https://script.google.com ，按「新專案」，專案名稱填「東浪預約」。
2. 把編輯器裡原本的內容全部刪掉，貼上 `apps-script/Code.gs` 的全部內容，然後儲存。
3. 在上方的函式選單選 `authorize`，按「執行」。依照畫面指示允許存取日曆和 Gmail。
   - 如果出現「Google 尚未驗證這個應用程式」，按「進階」，再按「前往東浪預約」。
4. 按右上角的「部署」，選「新增部署作業」。點齒輪圖示，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按「部署」，複製畫面上的「網頁應用程式網址」（結尾是 `/exec`），貼給 Claude。
   - 也可以自己改：把網址貼到 `index.html` 裡 `const BOOKING_API = "";` 的引號中間。

在填入這個網址之前，網站還是能用：客人可以算價格，再把預約訊息複製到 LINE 傳給你。

### 以後修改 Code.gs

改完之後，到「部署」→「管理部署作業」，按鉛筆圖示，版本選「新版本」，再按「部署」。網址不會改變。

## 可以調整的設定

- `index.html`
  - `OPEN_FROM`、`OPEN_UNTIL`：可預約的第一個和最後一個開始時間。目前是 10:00 到隔天 01:00。
- `Code.gs` 的 `CONFIG`
  - `BUFFER_MIN`：兩筆預約之間至少要隔多久，目前是 30 分鐘。
  - `MIN_LEAD_HOURS`：客人最快可以約幾小時後的時段，目前是 3 小時。
  - `EVENT_EXTRA_MIN`：日曆活動比課程多留的時間，目前是 20 分鐘，所以 100 分鐘的課程會佔 2 小時。
  - `NOTIFY_EMAIL`：通知信要寄到哪裡。留空就會寄給部署這支程式的帳號。
